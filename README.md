# Heart Failure Lab — Interactive Study Website

An offline-first interactive cardiology website rebuilt from the supplied Heart Failure chapter and modeled on the attached interactive lab, with a more modular content structure and additional clinical-reasoning tools.

## Open the website

1. Extract the archive.
2. Keep all files together in the same folder.
3. Open `index.html` in a modern browser.

No installation, server, account, or internet connection is required for the core website. External guideline links require internet access.

## Included features

- 32 interconnected modules in six learning groups
- Responsive sidebar navigation and module-to-module links
- Global search, bookmarks, visited-module progress, and keyboard shortcuts
- Light and dark modes
- Section-level text-to-speech with pause and continuation from the stopped position
- EF phenotype, bedside profile, and therapy-reasoning laboratories
- 12 clinical cases
- 60 sectioned flip cards
- 30-question scored quiz
- Embedded original source PDF
- Print-friendly layout that stays white and readable from either theme
- Supplemental study hub, notes, focus mode, and spaced-review controls

## Main files

- `index.html` — website shell and navigation interface
- `content.js` — structured Heart Failure content, cases, flashcards, and quiz bank
- `app.js` — routing and interactive learning tools
- `styles.css` — core responsive design and print rules
- `upgrades.js` / `upgrades.css` — enhanced TTS, study hub, focus mode, notes, and accessibility utilities
- `heart-failure-source.pdf` — supplied source chapter

## Educational scope

This website is for medical education and revision. It is not a clinical decision-support system and does not replace current prescribing information, local protocols, or individualized patient assessment.
